# Refresh Rate (Quest)

1. Create a free GitHub repo and upload everything in this folder (keep the `.github` folder).
2. Open the **Actions** tab -> **Build APK** -> wait for the green check.
3. Open the finished run, download the **RefreshRate-apk** artifact, unzip it, install `app-debug.apk`.

On the headset: Settings -> Developer -> Wireless Debugging -> on.
"Pair device with pairing code" shows a pairing port and a 6-digit code (enter both once).
The main Wireless Debugging screen shows the connect port (enter it, then tap a rate).
